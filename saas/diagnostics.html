ตรวจสอบการเปิดครูพัสดุ

ตรวจการทำงานเฉพาะเบราว์เซอร์นี้ โดยไม่ต้องเข้าสู่ระบบ

หน้านี้ตรวจไฟล์เว็บไซต์ การเชื่อมต่อ และขั้นตอนล่าสุดที่แอปเริ่มทำงานใน Chrome โดยไม่อ่านรหัสผ่านหรือข้อมูลในเอกสาร

  • กำลังเริ่มตรวจสอบ…รอสักครู่
กลับหน้าครูพัสดุ
หากโปรไฟล์ Chrome อื่นเปิดได้: ลองปิดส่วนขยายที่ติดตั้งในโปรไฟล์นี้ชั่วคราว แล้วเปิดหน้าเว็บใหม่ หากยังไม่ได้ ให้ลบข้อมูลเว็บไซต์เฉพาะ kru-pasadu.vercel.app ใน Chrome → การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย → การตั้งค่าเว็บไซต์ → ดูสิทธิ์และข้อมูลที่เก็บในเว็บไซต์ การลบข้อมูลเว็บไซต์จะทำให้ออกจากระบบ และอาจลบแบบร่างที่ยังไม่บันทึก แต่ไม่ลบเอกสารที่เก็บบนเซิร์ฟเวอร์
หมายเหตุ: การทดสอบ CDN เป็นเพียงการตรวจการเชื่อมต่อ ไม่ยืนยันว่า Chrome สามารถรันโมดูลทุกตัวได้ และหน้านี้ไม่ตรวจส่วนขยายโดยตรง
